# Ariapura — Relaunch Digitale (Demo)

Speculative demo for ariapura.org — Italian HVAC sanitation specialist (Bologna). 3 design variants in single HTML, sticky top-right switcher.

## Status

Last reviewed: September 2026 · release v2026.09

## Variants

| | Axis | Palette | Type |
|---|---|---|---|
| **V1 Clinical** | Medical-institutional | Graphite / ivory / air-blue / deep teal | Fraunces + Inter |
| **V2 Eco-Medico** | Premium ESG | Forest / bone / brass / sage | Cormorant + Manrope |
| **V3 Industrial-Luxe** | Modern industrial trust | Charcoal / warm white / mint / terracotta | Fraunces + DM Sans |

## Stack

- Static HTML + Tailwind CDN + vanilla JS · no build step
- Italian copy throughout (Lei, sobrio, autorevole)
- Schema: `HVACBusiness` + `Service` + `Offer` (free check-up) + `FAQPage`
- Web3Forms placeholder for the form (replace `REPLACE_WITH_WEB3FORMS_KEY`)

## What's in /docs

- `RESEARCH.md` — competitor + niche + palette + SEO + EEAT + schema picks
- `GROWTH-PLAN.md` — **one-page closed-loop funnel plan**: LP → Ads → GHL CRM → n8n → Reviews → SEO. Stack + KPI + roadmap.
- `CLIENT-MESSAGE.md` — verbatim Italian pitch (paste-ready)
- `CLIENT-PITCH.md` — pitch log + scope Qs + pre-send checklist

## Why this beats current ariapura.org

1. **Schema markup absent on current site** — added `HVACBusiness` + `FAQPage` for organic + GMB
2. **Single-page brochure → conversion LP** — sectorial routing, dual CTA, trust strip, FAQ
3. **Concrete free check-up deliverable** — "sopralluogo + video-ispezione + tampone + report 48h" beats generic "preventivo gratuito"
4. **GHL + n8n automation loop** designed in `GROWTH-PLAN.md` — closes lead-to-revisita cycle no top competitor has
